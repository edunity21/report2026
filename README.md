# 2026 교육활동 성과보고서 — 웹 버전

순천승평중학교 교사 유정준의 「2026 교육활동 성과보고서」(A4 100쪽)를 웹에서 한 쪽씩 넘겨 볼 수 있게 만든 페이지입니다.
인쇄용 PDF와 같은 디자인을 그대로 보여 주고, 화면 폭에 맞춰 자동으로 크기를 맞춥니다.

## 1. 폴더 구조

이 구조를 그대로 유지해야 이미지와 글꼴이 보입니다. (모든 폴더가 저장소 맨 위에 있습니다)

> `2026-annual-report.pdf`는 용량 때문에 압축파일과 **따로** 드렸습니다. 압축을 푼 폴더 안(index.html 옆)에 넣어 주세요.

```
index.html                 보고서 본문(100쪽) + 차례·쪽 넘김 화면
2026-annual-report.pdf     PDF 원본(내려받기 단추와 연결, 약 23MB)
README.md                  이 안내서
fonts/   (7개)             Pretendard 글꼴
hero/    (11개)            표지·부 표지 그림
qr/      (8개)             플랫폼 QR 코드
img1/    (87개)            본문 사진·그림 ①
img2/    (87개)            본문 사진·그림 ②
```

## 2. GitHub에 올리기 (웹 업로드)

GitHub 웹 업로드는 **한 번에 100개 파일, 파일당 25MB**까지만 됩니다. 그래서 세 번에 나눠 올립니다.

1. `github.com/edunity21` 에서 **New repository** → 이름 `report2026` → **Public** → Create.
2. **1차** — 저장소 첫 화면 **Add file → Upload files** 에
   `index.html`, `README.md`, `2026-annual-report.pdf`, `fonts` 폴더, `hero` 폴더, `qr` 폴더를 한꺼번에 끌어다 놓고 **Commit changes**. (29개)
3. **2차** — 다시 **Add file → Upload files** 에 `img1` 폴더를 통째로 끌어다 놓고 **Commit changes**. (87개)
4. **3차** — 같은 방법으로 `img2` 폴더를 올리고 **Commit changes**. (87개)
5. **Settings → Pages → Branch** 를 `main` / `(root)` 로 지정하고 **Save**.
6. 1~2분 뒤 `https://edunity21.github.io/report2026/` 에서 열립니다.

> 폴더를 끌어다 놓으면 폴더 이름(`img1/` 등)이 경로로 그대로 잡힙니다. 폴더 안의 파일만 따로 고르면 경로가 사라져 그림이 안 보이니, **폴더째** 올려 주세요.
>
> GitHub Desktop이나 git을 쓰면 폴더 전체를 한 번에 올려도 됩니다.

### [확인]
- 첫 화면에 표지 그림과 “소리로 잇고, 기술로 짓고, 동료와 넓히다”가 보이면 1차 성공.
- 16쪽(ME 프로젝트 사진)·39쪽(플랫폼 QR)·62쪽(진로 체험 사진)이 모두 보이면 2·3차 성공.

## 3. 보는 방법

| 동작 | 방법 |
|---|---|
| 차례 열기 | 왼쪽 위 **차례** 단추 → 원하는 항목을 누르면 그 쪽으로 이동 |
| 한 쪽씩 넘기기 | 키보드 **← / →** (또는 PageUp / PageDown), 오른쪽 아래 ‹ › 단추 |
| 처음·끝 | **Home / End**, 오른쪽 아래 ⤒ 단추 |
| 특정 쪽 바로 열기 | 주소 뒤에 `#p35` 처럼 쪽 번호 붙이기 (예: `.../report2026/#p59`) |
| PDF 내려받기 | 오른쪽 위 **PDF** 단추 |
| 인쇄 | 브라우저 인쇄(Ctrl+P) — 화면 단추는 빠지고 A4 한 쪽씩 인쇄됩니다 |

휴대폰에서는 화면 폭에 맞춰 쪽 전체가 작게 보입니다. 두 손가락으로 확대해서 읽거나, PDF를 내려받아 보세요.

## 4. 공개 전 확인 사항

- **학생 사진** — 보고서의 학생 사진은 모두 모자이크 처리본이지만, 공개 주소에 올리기 전에 학교의 초상 이용 동의 범위를 한 번 확인해 주세요.
- **검색 노출 차단** — `index.html` 위쪽에 `<meta name="robots" content="noindex, nofollow">` 한 줄을 넣어 두어 검색엔진에는 나오지 않습니다. 주소를 아는 사람만 보게 하려는 설정이며, 검색에 노출하려면 그 한 줄을 지우면 됩니다.
- **심사 결과** — 연구대회 심사 결과는 2026. 10. 7. 기준 ‘심사 대기’로 적혀 있습니다. 결과가 나오면 내용을 고친 새 판을 만들어 `index.html`과 PDF만 바꿔 올리면 됩니다.

## 5. 기술 메모

- 별도 서버나 라이브러리 없이 HTML 파일 하나로 동작합니다. 제목용 명조(Noto Serif KR)만 Google Fonts에서 불러옵니다.
- 본문 그림은 화면에 가까워질 때 불러오도록(lazy loading) 해 두어 첫 화면이 빨리 뜹니다.
